# Система голосования за установку домофонов

## Описание
PHP 8.3 + MySQL система для управления голосованием жильцов многоквартирных домов за установку домофонов.

## Возможности

### Для жителей:
- ✅ Создание подъездов для голосования
- ✅ Голосование "За" или "Против" установки домофона
- ✅ Отслеживание прогресса голосования в реальном времени
- ✅ Автоматическое создание протокола при достижении 51% голосов "ЗА"
- ✅ Автоматическая генерация договора на установку
- ✅ Интеграция с Telegram для создания чатов подъездов
- ✅ **Интеграция с MAX Messenger** для уведомлений и групповых чатов
- ✅ Онлайн-оплата через YooKassa
- ✅ Отзывы с AI-модерацией
- ✅ Вопросы и ответы с AI-помощником

### Для администраторов:
- ✅ Панель управления с расширенной статистикой
- ✅ Настройка порога голосования
- ✅ Управление интеграциями (Telegram, MAX Messenger, YooKassa, GigaChat, Yandex)
- ✅ Просмотр всех платежей
- ✅ **Расширенная модерация контента** с журналом действий
- ✅ **Настройки сайта** (дизайн, уведомления, платежи, интеграции)
- ✅ **Управление страницами сайта** (о компании, контакты, политика конфиденциальности)
- ✅ **Логирование действий администраторов**
- ✅ **Очередь уведомлений** для отправки через различные каналы
- ✅ **Статистика по MAX Messenger** (отправленные уведомления, группы, успешность доставки)

## Новые таблицы базы данных

### MAX Messenger интеграция:
- `max_groups` - группы чатов для подъездов
- `max_notifications` - журнал отправленных уведомлений
- `user_accounts` - аккаунты пользователей в мессенджерах
- `user_entrances` - привязка пользователей к подъездам
- `meeting_responses` - ответы на приглашения собраний

### Модерация и настройки:
- `site_settings` - расширенные настройки сайта (дизайн, уведомления, интеграции)
- `moderation_logs` - журнал действий модерации
- `admin_actions_log` - лог действий администраторов
- `website_pages` - управляемые страницы сайта
- `notifications_queue` - очередь уведомлений

## Установка

### 1. Требования
- PHP 8.3+
- MySQL 8.0+
- Веб-сервер (Apache/Nginx)

### 2. Настройка базы данных

```bash
mysql -u root -p < database/schema.sql
```

### 3. Конфигурация

Отредактируйте `config/config.php`:

```php
'db' => [
    'host' => 'localhost',
    'name' => 'intercom_system',
    'user' => 'ваш_пользователь',
    'password' => 'ваш_пароль',
],
'app' => [
    'telegram_bot_token' => 'ваш_token_от_BotFather',
    'yookassa_shop_id' => 'ваш_shop_id',
    'yookassa_secret_key' => 'ваш_secret_key',
    'gigachat_client_id' => 'ваш_client_id',
    'gigachat_client_secret' => 'ваш_client_secret',
    'yandex_api_key' => 'ваш_api_key',
]
```

## Использование

### 1. Создание подъезда для голосования
1. Откройте главную страницу
2. Заполните форму: адрес, номер подъезда, количество квартир
3. Нажмите "Создать и пригласить жильцов"
4. Получите ссылку на Telegram-чат

### 2. Голосование
1. Перейдите на страницу голосования по ссылке
2. Введите ФИО, телефон, номер квартиры
3. Выберите "ЗА" или "ПРОТИВ"
4. При достижении 51% голосов "ЗА" автоматически создается протокол

### 3. Админ-панель
1. Перейдите на `/admin.php`
2. Пароль по умолчанию: `admin123` (измените в production!)
3. Настройте интеграции и просмотрите статистику
